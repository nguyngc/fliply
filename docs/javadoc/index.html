Summary

Purpose:

  • Fliply is a JavaFX desktop application for managing flashcards, generating quizzes, and classroom management with multi-language support.
  • The JavaDoc files are located at docs/javadoc/. Open the site/index.html file to view the full API documentation.

Short instructions

  1. To view the documentation locally: open docs/javadoc/index.html in your browser.
  2. To submit a single file: use target/fliply-javadoc.zip which contains all HTML files.
  3. To update the JavaDoc: add Javadoc comments (/** ... */) to the source code, regenerate the JavaDoc locally, and copy the generated HTML back to docs/javadoc/ if you want it included in the repo.

Notes

Additional info:

  • The folder docs/javadoc/ is a static snapshot generated once — you may commit it to the repository so it remains visible in the project.
  • The temporary options files under target/javadoc-bundle-options/ were generated by the Maven plugin and can be safely removed.
