Nội dung tóm tắt

Mục tiêu:

  • Fliply là ứng dụng desktop JavaFX quản lý flashcards, tạo quiz, quản lý lớp học và hỗ trợ đa ngôn ngữ.
  • Thư mục JavaDoc hiện tại: docs/javadoc/ (đã được tạo 1 lần). Mở docs/javadoc/index.html để xem đầy đủ.

Hướng dẫn ngắn

  1. Để xem toàn bộ documentation: mở docs/javadoc/index.html bằng trình duyệt (double-click hoặc Open with browser).
  2. Nếu muốn nộp 1 file duy nhất: gửi target/fliply-javadoc.zip (đã chứa toàn bộ HTML).
  3. Nếu cần cập nhật JavaDoc: thêm comment /** ... */ trong source, sau đó chạy Maven (local) để regen và copy lại vào docs/javadoc/.
